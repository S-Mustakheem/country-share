# country-share
1. Project Title / Headline
Key Business Questions & Analysis Themes.

2. Short Discription / Purpose
This Power BI dashboard delivers an end-to-end workforce analytics solution designed to examine organizational headcount, diversity, compensation structures, employee performance, and regional benchmarks. By transforming raw HR data into interactive visual insights, this tool enables HR leaders and executives to make data-driven decisions regarding talent distribution, salary equity, and performance evaluation.   

3. Example:
The dashboard directly answers 10 critical workforce questions:
Departmental Headcount: What is the total staff distribution across each department?
Gender Distribution: How is gender diversity represented across different departments?
Staff Age Spread: What does the age distribution histogram reveal about workforce demographics?
Compensation Ranges: What are the minimum, maximum, and average salaries per department?
Top Earners by Country: Who are the highest-compensated employees in each geographic market?
Performance Spread: Interactive sorting and ranking of workforce performance ratings.
Company Growth Trend: How has headcount grown historically over time?
Employee Alpha Filter: Quick-search capability allowing filtering by employee starting letter.
Performance vs. Compensation: Is there a measurable correlation between an employee's salary and their performance rating?
Regional Benchmarking (India vs. UK): A comparative scorecard evaluating headcount, performance, and pay scale across two major hubs.

4. 🧰Tech Stack & Key Features
Power BI Desktop: Dashboard visual design, canvas layout, and user experience.
Power Query : Data extraction, transformation, cleaning, data type enforcement, and custom field generation.
DAX (Data Analysis Expressions): Dynamic measures for key KPIs, performance rankings, statistical salary range summaries (MIN, MAX, AVERAGE), and conditional logic.
Interactive Slicers & Drill-Throughs: Cross-filtering across departments, geography, performance buckets, and custom alphabet filters.
